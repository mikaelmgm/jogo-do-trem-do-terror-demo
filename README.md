# Casa Assombrada · demo

Demo jogável do trem fantasma, para testar no navegador.

- **Jogar:** https://mikaelmgm.github.io/jogo-do-trem-do-terror-demo/
- `index.html` é o jogo em 3D e `classico.html` é a versão 2D em pixel art.

Protótipo: o progresso fica salvo só no navegador, a carteira é de teste e vários personagens são de terceiros.
